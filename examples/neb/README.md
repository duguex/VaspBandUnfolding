# NEB Energy Path (PES)

| Field | Value |
|---|---|
| Feature IDs | D2 |
| Level | L1 — experimental |
| Citation | no |
| Runner | `bash run.sh` |

## Purpose

Reads minimal OUTCAR stubs with `energy  without  entropy` lines from 3
image directories along a reaction path and writes the potential energy
surface (`ref/pes.dat`) with reaction coordinate and energy.

## Inputs

None — fake OUTCAR stubs are generated by `run.py`.

## Requirements

No special Python packages beyond the standard library.

## Command

```bash
bash run.sh
```

Exit codes: `0` success, `2` missing OUTCAR data, `1` failure.

## Expected outputs

- `ref/pes.dat` — 3 data points (reaction coordinate vs energy)

## Assumptions

See `docs/ASSUMPTIONS.md` sections: VASP energy parsing, NEB.
